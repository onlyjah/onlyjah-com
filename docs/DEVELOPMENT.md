The application checkout is `onlyjah-rebuild`. The adjacent Clerk starter is reference material with independent local edits. The existing `onlyjah-com` folder is another worktree of this Git repository on `main`. Never substitute one folder's environment, branch or package manager for another.

`test` is staging; `testing` is its release mode. `dev/**` and `rebuild/**` branches run the same checks as staging but do not automatically publish to Railway. `main` remains the production history. Start each context by reading this document and `docs/README.md`, then inspect `git status --short --branch`, `git log -5 --oneline` and the current remote head. Fetch before comparing. Prefer an isolated branch per task and open a pull request against `test` after `pnpm check` passes. Avoid working simultaneously in the same checkout from two windows. There is no automatic conversation or private-master synchronization.

Use Node 24 LTS (`nvm use`) and the version of pnpm pinned in package.json. Run `pnpm install --frozen-lockfile --ignore-scripts`. Direct dependencies are exact versions; update them intentionally together with pnpm-lock.yaml. React's types match its 19.3 runtime. No Nitro beta is required. Native TanStack Start prerenders the public artifact; the temporary server compilation is removed after the build. `.output/public` is the only site upload directory.

Run `pnpm check`, then review `git diff --check` and the exact staged paths. The checks cover formatting, UI/static boundaries, quote provenance, copy approvals for the selected release mode, build, types, behavioral tests, meaningful route HTML and HTTP direct links. A testing build allows pending wording review; a publication build requires approvals. Passing checks never creates a payment, publishing grant, production migration or invitation.

`pnpm export:ui` creates a new ignored, hashed export under `exports/`; it never overwrites an existing snapshot. See [UI package](templates/UI-PACKAGE.md) for TanStack and Astro consumption. Site copy and photographs require separate provenance and author/license review.
